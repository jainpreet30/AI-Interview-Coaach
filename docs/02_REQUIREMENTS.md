# Requirements

## Functional Requirements
- User signup, login, and profile management
- Role-based access for students, coaches, and administrators
- Interview session creation, scheduling, and tracking
- Question bank with categories, tags, and difficulty labels
- AI-generated mock interview questions and answer evaluation
- Feedback and performance analytics after each session
- Save practice history and generate progress reports
- Admin management for question library and user accounts

## Non-Functional Requirements
- Responsive modern UI with intuitive navigation
- Secure authentication and session management
- Scalable backend supporting multiple concurrent users
- Reliable REST API with consistent responses and error handling
- Maintainable and modular codebase following MERN best practices
- Deployment readiness with environment configuration and CI/CD support

## System Requirements
- Node.js 18+ and npm or Yarn
- MongoDB Atlas or self-managed MongoDB instance
- React 18+ for the client application
- Express.js for the backend API
- AI integration via OpenAI-compatible API or local model connector
- GitHub repository for source control and documentation

## Constraints and Assumptions
- AI service credentials are stored securely using environment variables
- Initial implementation is web-only; native mobile app is out of scope
- Real-time voice interviews are optional and not required for MVP
- Offline access is not required for the first delivery
