# User Stories

## Persona: Student
- As a student, I want to register and create a profile so I can access interview practice.
- As a student, I want to choose interview categories so I can practice relevant topics.
- As a student, I want to submit answers and receive AI feedback so I can improve my performance.
- As a student, I want to view my practice history so I can track progress over time.
- As a student, I want to receive suggested follow-up questions so I can strengthen weak areas.

## Persona: Coach/Interviewer
- As a coach, I want to review student session summaries so I can identify improvement areas.
- As a coach, I want to add and manage interview questions so I can maintain a relevant question bank.
- As a coach, I want to view analytics across students so I can measure preparation effectiveness.

## Persona: Admin
- As an administrator, I want to manage users and roles so I can ensure appropriate access controls.
- As an administrator, I want to deploy new question categories so the system remains up to date.
- As an administrator, I want to monitor system usage so I can support the project deployment.

## Acceptance Criteria
- The application supports role-based access and redirects users to appropriate dashboards.
- Interview sessions include AI-based questions and feedback.
- Users can save and revisit past interview attempts.
- Admin can create, edit, and delete questions safely.

## Priority
- Must have: student practice flow, AI feedback, authentication, basic dashboard
- Should have: analytics, question management, progress reports
- Could have: advanced coaching tips, export feature, admin metrics
