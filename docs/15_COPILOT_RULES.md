# Copilot Rules

## Development Guidelines
- Use Copilot to accelerate boilerplate generation, but review generated code carefully.
- Keep prompts specific and include the current file or context when asking for code suggestions.
- Use clear commit messages and maintain a logical branch workflow.

## Code Quality
- Follow consistent naming conventions for variables, components, and routes.
- Write small, focused functions and reusable React components.
- Prefer explicit error handling and meaningful log messages.
- Document assumptions and architectural decisions in the `docs/` folder.

## Collaboration and Version Control
- Commit frequently with small increments.
- Use feature branches for major improvements such as AI integration or UI redesign.
- Keep `main` branch stable and synced with the production-ready state.

## Report Preparation
- Track progress in the `docs/13_ROADMAP.md` file and update it as work completes.
- Keep a list of implemented features, testing results, and deployment links for the final report.
- Capture screenshots and notes during development for the GTU project documentation.
