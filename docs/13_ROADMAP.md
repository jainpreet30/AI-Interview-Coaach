# 15-Day Roadmap

## Phase 0: Planning and Documentation (Days 1-2)
- Finalize project concept and documentation structure
- Define requirements, features, and user stories
- Design folder structure and architecture
- Create repository skeleton and initial README

## Phase 1: Backend and Database (Days 3-5)
- Initialize Node/Express backend
- Define MongoDB schema and models
- Implement authentication and user routes
- Build question bank and interview session APIs
- Add validation and error handling

## Phase 2: Frontend and UI (Days 6-9)
- Initialize React frontend and routing
- Build login, dashboard, and interview session pages
- Implement question browsing and session flows
- Add analytics and feedback components
- Apply responsive UI styling and modern design patterns

## Phase 3: AI Integration (Days 10-12)
- Integrate AI provider for question generation and answer evaluation
- Implement prompt templates and backend connector
- Display AI feedback and coaching tips in the UI
- Validate AI response handling and error fallback behavior

## Phase 4: Testing, Deployment, and Report (Days 13-15)
- Write unit and integration tests for backend and frontend
- Set up continuous integration and run test pipelines
- Deploy frontend, backend, and database
- Prepare GTU report material, screenshots, and documentation
- Polish UI, fix bugs, and prepare demo assets

## Deliverables
- Working MERN application with AI-assisted interview coaching
- Completed professional documentation and GitHub repository
- Fully documented deployment and testing workflows
- GTU report-ready artifacts and final presentation notes
